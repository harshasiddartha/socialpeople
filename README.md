# Social People Agency Website 🚀

A modern, high-performance web application for **Social Monks / Social People Agency** — a people-first media agency combining cultural insight, brand strategy, creative production, and performance media to turn attention into long-term growth.

---

## ✨ Features

- **Responsive & Modern UI:** Designed with high attention to detail, typography, and color aesthetics.
- **Service Highlights:** Interactive layout presenting core services, core values, process blueprints, and client testimonials.
- **Client & Partner Showcase:** Integrated client roster and testimonial sections.
- **Optimized Typography:** Powered by `next/font` with the Geist font family for clean readability.
- **Fast Performance:** Server-Side Rendering (SSR) and optimized asset delivery with Next.js App Router.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) / PostCSS
- **Deployment:** [Vercel](https://vercel.com/)
